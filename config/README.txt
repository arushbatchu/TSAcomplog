Put the arena config files in this folder (or any folder you pass to run.py):

  supply chain - data - material requirements.xlsx
  supply chain - data - suppliers.xlsx
  supply chain - data - processors.xlsx
  supply chain - data - distributors.xlsx
  supply chain - data - distances.xlsx
  supply chain - data - shipping cost.xlsx
  solution - template.xlsx          (pass with --template)

Files with "solution" in the name are ignored by the loader, so the template
and the exemplars can sit in here safely.
